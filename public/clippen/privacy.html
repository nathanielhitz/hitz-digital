Clippen – Privacy Policy

Last updated: 7 October 2026

This policy describes what personal data Clippen processes. Clippen is a personal tool operated by Hitz Digital (Netherlands) that publishes short videos, made from public Twitch clips, to the operator's own TikTok and YouTube accounts.

1. Who uses Clippen

Only the operator uses Clippen. Nobody else can sign in, connect an account, or have content posted on their behalf. Clippen therefore collects no data from TikTok users other than the operator.

2. Data Clippen processes

Account access tokens. When the operator connects a TikTok or YouTube account, the platform issues an access token. Clippen stores this token in a file on the operator's own computer, uses it only to upload videos, and never shares it.

Basic profile information. Through the TikTok user.info.basic scope Clippen reads the display name and avatar of the connected account, to confirm which account is connected. This is not stored beyond the session.

Public Twitch clips. Clippen downloads public clips, including the audio, the streamer's channel name and the clip title, to produce the video. These are public data published by the streamer on Twitch. Rendered videos and transcripts are deleted from the operator's computer after seven days.

Transcripts. The audio of each clip is transcribed locally. The transcript, with the clip title and the streamer name, is sent to Anthropic's Claude API to write the title and caption. Anthropic processes this data under its own privacy policy and does not use API data to train models.

3. YouTube API Services

Clippen uses YouTube API Services to upload videos to the operator's own YouTube channel. By using Clippen, the operator agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Clippen requests one Google permission, youtube.upload, and uses it only to call the videos.insert method. It does not read, list, search, update or delete any YouTube data. The data Clippen stores from Google is limited to the OAuth token of the operator's account and the YouTube video IDs of the videos it uploaded, kept in a local database on the operator's computer to avoid duplicate uploads. No other YouTube user data is accessed or stored, and nothing is shared with third parties.

The operator can revoke Clippen's access to the Google account at any time via the Google security settings page. Deleting the local token file removes the stored credential; stored video IDs are deleted on request via the contact address below.

4. What Clippen does not do

Clippen does not use cookies, analytics or advertising. It does not sell or share personal data, and it does not collect data from viewers of the published videos.

5. Where data is stored

All data is stored on a computer in the Netherlands controlled by the operator. Published videos are stored by TikTok and YouTube under their own policies.

6. Your rights

Twitch streamers whose clips appear in a Clippen video can ask for the video to be removed and for their channel to be excluded from future runs. Anyone can request access to, correction of, or deletion of personal data by emailing the address below. The operator responds within 30 days.
